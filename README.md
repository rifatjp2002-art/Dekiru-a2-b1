## 🌟 মূল বৈশিষ্ঠ্যসমূহ (Key Features)

### 📊 ১. ইন্টারেক্টিভ লার্নিং ড্যাশবোর্ড (Comprehensive Dashboard)
* **লাইভ অগ্রগতি ট্র্যাকার:** লেসন-বাই-লেসন পড়ার অগ্রগতি সুন্দর ভিজ্যুয়াল প্রগ্রেস বারে দেখতে পাবেন।
* **৪-ধাপের শব্দ দক্ষতা স্তর:** আপনার আয়ত্ত করা শব্দগুলোকে ৪টি ভাগে ট্র্যাক করা হয় (🟢 Mastered, 🟡 Learning, 🔴 Hard Words, ⚪ Unstudied)।
* **কঠিন শব্দের স্পটলাইট (Spotlight):** যে শব্দগুলো আপনার বেশি ভুল যায়, ড্যাশবোর্ডে সেগুলো আলাদা ফোকাস বক্সে হাইলাইট করা থাকে যাতে দ্রুত রিভিশন দেওয়া যায়।

### 🗂️ ২. স্পেসড রিপিটিশন ফ্ল্যাশকার্ড (SRS Flashcards)
* **বিজ্ঞানসম্মত স্পেসড রিপিটিশন (SRS):** প্রতিটি শব্দ পড়ার পর নিজের আত্মবিশ্বাস অনুযায়ী **Easy / Good / Hard** সিলেক্ট করতে পারবেন, যা পরবর্তী সময়ে পড়ার রিমাইন্ডার নির্ধারণ করে।
* **সহজ টেক্সট-পিকিং এবং হাইড/শো:** কার্ডের ইংরেজি বা বাংলা অর্থ ও উচ্চারণ লুকিয়ে রেখে মনে করার চেষ্টা করতে পারবেন এবং ট্যাপ করে পীক (peek) করতে পারবেন।

### 🎯 ৩. টাইমার-ভিত্তিক JLPT কুইজ (Timed Scenario Quizzes)
* **টাইম-লিমিট অপশন:** ১০ সেকেন্ড, ১৫ সেকেন্ড বা ৩০ সেকেন্ডের দ্রুত গতির এমসিকিউ পরীক্ষা।
* **ডুয়াল ডিরেকশন কুইজ:** জাপানি থেকে বাংলা অথবা বাংলা থেকে জাপানি—উভয় উপায়ে নিজেকে যাচাই করুন।
* **ভুল সংশোধনের সুযোগ (Mistake Re-test):** কুইজে কোনো শব্দ ভুল হলে গেম ওভারের পর কেবল সেই ভুল করা শব্দগুলোর ওপরে পুনরায় টেস্ট দিয়ে ১০০% রিভিশন শেষ করতে পারবেন।
* **টানা সঠিক উত্তরের রেকর্ড:** লাইভ স্কোরবোর্ড এবং হাইয়েস্ট স্ট্রিক ট্র্যাকার।

### 🔊 ৪. হাই-ফিডেলিটি টেক্সট-টু-স্পিচ (HD TTS Audio)
* ব্রাউজারের নেটিভ জাপানি রিডিং সিন্থেসাইজার ইঞ্জিন ব্যবহার করে নিখুঁত বিশুদ্ধ জাপানি টোনে উচ্চারণ।
* **গতি নিয়ন্ত্রণ:** আপনার সুবিধামতো পড়ার স্পিড কমিয়ে-বাড়িয়ে নিতে পারবেন (**0.75x**, **0.9x**, বা **1.0x**)।

## ⚡ প্রো-লেভেল পারফরম্যান্স অপ্টিমাইজেশন (Elite Optimizations)

মোবাইল স্ক্রিনে মেমোরি এবং র‍্যামের সর্বোচ্চ সাশ্রয় নিশ্চিত করতে অ্যাপটি বিশেষভাবে অপ্টিমাইজড করা হয়েছে:

* **লেজি অন-ডিমান্ড লোডিং (Dynamic Pagination):** ১০৩৩টি শব্দ একসাথে স্ক্রিনে লোড না করে ডিফল্টভাবে প্রতিটি লেসনের জন্য মাত্র ১৫টি শব্দ রেন্ডার করা হয়। এর ফলে ফোনের ওপর কোনো চাপ পড়ে না এবং অ্যাপ কখনো ল্যাগ করবে না। নিচে থাকা **"🔽 আরো শব্দ লোড করুন"** বাটন ট্যাপ করে চাহিদামতো শব্দ যুক্ত করা যায়।
* **স্ক্রোল পজিশন মেমোরি (Scroll Restoration):** শব্দ তালিকায় কোনো শব্দকে বুকমার্ক করলে বা ট্যাব পরিবর্তন করে পুনরায় ফিরে আসলে আপনার বর্তমান স্ক্রোলিং পজিশন নিখুঁতভাবে মনে থাকে।
* **১০০% অফলাইন সাপোর্ট (Full PWA Client-Side Cache):** ইন্টারনেট সংযোগ ছাড়াই অ্যাপটি সম্পূর্ণ অফলাইনে কাজ করে এবং আপনার স্টাডি রেকর্ড ও স্কোর সরাসরি ব্রাউজারের `localStorage`-এ সুরক্ষিত থাকে।

## 🛠️ লোকাল সেটআপ এবং রান করার নিয়ম (Developer Guide)

প্রজেক্টটি আপনার লোকাল পিসিতে রান করার জন্য নিচের ধাপগুলো অনুসরণ করুন:

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/rifatjp2002-art/Dekiru-a2-b1.git

# ২. ডিরেক্টরিতে প্রবেশ করুন
cd Dekiru-a2-b1

# ৩. ডিপেন্ডেন্সি ইন্সটল করুন
npm install --legacy-peer-deps

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

লোকালহোস্টে ওপেন করতে ব্রাউজারে যান: `http://localhost:3000`
