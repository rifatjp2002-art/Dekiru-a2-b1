# できる日本語 Vocabulary (A2-B1)

An advanced, modular Japanese vocabulary learning web application designed exclusively for **できる日本語 Pre-Intermediate (Lessons 1–15)** (A2–B1 level) learners by **Rifat Ahmed**.

## Features
- 📚 **Full Vocabulary Dataset (Lessons 1–15)** with Furigana, Katakana On'yomi, Hiragana Kun'yomi, Romaji, English, and Bengali meanings.
- 🗂️ **Interactive Flashcards** with SRS (Spaced Repetition System: Easy / Good / Hard).
- 🎯 **Timed JLPT Quiz Mode** with lesson selector, countdown timers (10s/15s/30s), streak counters, and mistake re-test logic.
- 📊 **Comprehensive Dashboard** with live lesson-by-lesson progress tracking and hard words spotlight.
- 🎯 **Can-Do Goals** alignment based on the official curriculum.
- 🔊 **TTS Audio Pronunciation** with speed controls (0.75x / 0.9x / 1.0x).
- 📱 **Fully Responsive Layout** optimized for Mobile, Tablet, and Desktop screens.

## 🚀 How to Deploy on GitHub Pages

1. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "Deploy Dekiru Nihongo Vocabulary A2-B1 App"
   git push origin main
   ```

2. **Automatic Deployment via GitHub Actions**:
   - Go to your Repository on GitHub -> **Settings** -> **Pages**.
   - Under **Build and deployment** -> **Source**, select **GitHub Actions**.
   - Vite static build will automatically compile to `dist/` and publish your site!

3. **Manual Build (Optional)**:
   ```bash
   npm run build
   ```
   The production static website output will be generated inside the `dist/` folder, ready to host on GitHub Pages, Netlify, Vercel, or Firebase Hosting.
